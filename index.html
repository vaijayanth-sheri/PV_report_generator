☀️ Solar PV Yield Calculator

This is a static deployment of the Solar PV Yield Calculator project.

The core application is built with Python, Streamlit, and pvlib, designed to estimate solar photovoltaic energy yield using PVGIS TMY weather data.

Because it is a Streamlit application, the interactive backend cannot run on a static file host (Netlify), but you can find the source code, reports, and documentation below.
